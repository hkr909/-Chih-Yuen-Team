## 已完成的功能

1. **电源系统**：2 节 18650 串联（7–8.4V）→ 遥控继电器 → XH2.54-2p → DC-DC 降压 5V，为主控、电机驱动、舵机供电。
2. **主控系统**：STM32F103C8T6 核心板，两排 1×20p 排母直插底板，ST-Link 调试。
3. **全向移动底盘**：4×TT 减速电机 + 麦轮，2×DRV8833 驱动，软件 PWM 调速，支持前进/后退/左右平移/原地旋转；运动分快速、慢速两档，可用手柄按键切换。
4. **方块夹取机构**：995 舵机×3 + SG90×1 共 4 路舵机，全部硬件 PWM，底板 4 个直插接口。
5. **PS2 遥控**：PS2 无线手柄 + 转接板，SPI1 通信，遥控整车平动、平移、旋转。
6. **PCB 集成底板**：自绘底板集成电源、主控、电机驱动、舵机、PS2 接口，完成两轮打板与焊接。
7. **整车结构与重量**：亚克力底盘承载各模块，按赛事 3.3.3 结构规范选材布线，实测整车重量 964g。

## 开源项目说明

本项目使用 STM32F1 HAL 驱动库（BSD-3-Clause）、CMSIS（Apache-2.0）与 STM32Cube 工程模板（BSD-3-Clause），
许可证与使用方式详见 [docs/智能车设计与制作日志.md](docs/智能车设计与制作日志.md) 的「开源项目与第三方库说明」一节。
业务代码（电机、舵机、PS2、运动解算、示教回放等）均为本队自行编写。
